# LTD Visual Explainer

A standalone presentation package containing four 16:9 slides and a self-playing, pausable LTD product walkthrough.

## Open

Open `index.html` directly in a browser, or serve the folder:

```powershell
python -m http.server 4173 --directory ltd-explainer
```

Then visit `http://localhost:4173`.

## Controls

- Use the top tabs for the overview, system, educator, student, and detailed explainer views.
- The detailed explainer has educator/student tabs, play/pause, previous/next, restart, and playback speed.
- Space pauses or resumes. Left/right arrows change steps.
- The student interactive question and reflection submit button can be clicked.
- Use the full-screen control for presenting.
- Print to PDF in landscape to export the four 16:9 slides; the interactive view is automatically omitted.
